# Network, storage, startup, and ZMQ marker review

Baseline: Bitcoin `e4fef4ae65c68ebd34774700dc4801c24313d469` (26.0rc3).
Target: Syscoin `d5fc88adc9992a25f26641ddb174a76e7bf64407`.

Read-only manual review of the corresponding entries in `results/audit.json.gz`, supplemented by the actual source and selected local commit history. The findings below concern provenance comments, not runtime defects. “Missing” means the concrete fork change has no local SYSCOIN annotation; “ambiguous” means an existing bare/nearby marker does not delimit the complete change. This is a bounded verified subset of the complete candidate inventory.
